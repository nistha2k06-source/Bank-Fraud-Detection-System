# Bank Fraud Detection System

A Java Web-based application designed to manage banking transactions and identify suspicious activities using MySQL.

## Project Overview
The Bank Fraud Detection System helps manage customer accounts, process deposits and withdrawals, maintain transaction records and monitor suspicious banking activities through fraud alerts.

## Features
- Banking dashboard
- Customer and account management
- Deposit and withdrawal operations
- Transaction history
- Fraud alert management
- Stored procedures
- Transaction management using COMMIT and ROLLBACK

## Technologies Used
- Java
- JSP and Servlets
- JDBC
- MySQL
- HTML and CSS
- Apache Tomcat 10.1
- NetBeans IDE

## Database Details
- Database Name: `banking_fraud_db`
- Tables: Customers, Accounts, Transactions, Fraud_Alerts
- Stored Procedure: `make_transaction`

## How to Run
1. Clone or download this repository.
2. Open the project in NetBeans IDE.
3. Configure the MySQL database connection.
4. Execute the database SQL scripts in MySQL Workbench.
5. Configure Apache Tomcat 10.1.
6. Run the project in the browser.

## Conclusion
This project demonstrates the practical implementation of Java Web technologies, MySQL database management, stored procedures and transaction processing for monitoring banking activities.
